# Background Library

Use this reference when a video needs reusable background styles, multiple style directions for a client, or a consistent visual system across scenes.

## Rules

- Keep backgrounds low-distraction. Text, UI, charts, and animation should remain code-rendered and readable.
- Generate backgrounds without text, icons, logos, UI labels, or focal objects unless they are purely decorative.
- Prefer 3-6 options for client choice, then apply the selected direction consistently.
- Save approved backgrounds as reusable assets when the project will produce multiple videos.
- For 16:9, generate at 1920x1080 or higher. For 9:16, generate at 1080x1920 or higher. For 1:1, generate at 1440x1440 or higher.

## Style Categories

### Clean Product Gradient

Use for SaaS demos, launch videos, clean explainers, and client presentations.

```text
A clean product-video background in [aspect ratio], soft layered gradient with subtle depth.
Palette: [brand colors or neutral palette].
No text, no logos, no icons, no UI, no focal object.
Very low contrast in the center so code-rendered text remains readable.
Premium SaaS launch style, restrained and polished.
```

### Paper Grain / Editorial

Use for creator education, essays, tutorials, and approachable knowledge videos.

```text
A subtle paper grain background in [aspect ratio], warm editorial tone.
Soft off-white base with very light texture and gentle color washes.
No text, no icons, no patterns, no focal point.
Designed to sit behind black code-rendered text and simple cards.
Clean, thoughtful, human, not corporate.
```

### Dark Analytics / Terminal

Use for AI tools, coding workflows, dashboards, data, and automation videos.

```text
A dark technical background in [aspect ratio], deep charcoal base with faint grid lines and soft terminal glow.
Subtle green and blue accents, no readable text, no logos, no UI panels.
Low distraction center area for code-rendered dashboards and captions.
Modern AI tooling mood, sharp but not noisy.
```

### Soft Studio Product

Use for hardware, apps, product UI, and premium client demos.

```text
A soft studio product background in [aspect ratio], gentle lighting, subtle floor-to-wall depth.
Neutral palette with [accent color] highlights.
No product object, no text, no logo, no props.
Clean space for code-rendered product UI and annotations.
Premium product demo style.
```

### Minimal Grid / Technical

Use for process videos, systems diagrams, AI workflow videos, and B2B explainers.

```text
A minimal technical grid background in [aspect ratio], very subtle lines and coordinate marks.
Palette: [light/dark] with restrained accent color.
No labels, no numbers, no icons, no UI.
Designed for overlaying code-rendered flowcharts, cards, and captions.
Precise, calm, professional.
```

### Warm Education / Tutorial

Use for beginner tutorials, student-facing videos, and friendly tool explainers.

```text
A warm education video background in [aspect ratio], soft neutral base with gentle color blocks.
Friendly, readable, low visual noise.
No text, no icons, no classroom objects, no people.
Designed for code-rendered tutorial cards and subtitles.
Approachable but not childish.
```

### Cinematic Abstract

Use for trailers, launch teasers, and emotional opening sequences.

```text
A cinematic abstract background in [aspect ratio], soft volumetric light, restrained contrast.
Palette: [specific palette].
No text, no logos, no objects, no recognizable scene.
Dark enough for bright code-rendered typography, but not muddy.
Premium trailer mood, subtle movement implied.
```

## Client Choice Format

When style is unclear, present options like this:

```text
I suggest generating 4 background directions:
1. Clean product gradient - best for SaaS/client demos.
2. Paper grain editorial - best for knowledge/tutorial content.
3. Dark analytics terminal - best for AI/coding workflows.
4. Warm education tutorial - best for beginner-friendly videos.

Please choose one direction, or ask for mixed variants.
```
